PDF Toolkit – PDF Merger, Splitter & Text Extractor (Full-Stack Python Application)

1. Project Objectives & Problem Statement

In modern digital workflows, students and professionals frequently need to manipulate PDF documents—merging lecture notes, splitting report chapters, extracting tables for analysis, or running OCR on scanned documents.

Most existing online PDF tools either charge subscription fees, require uploading confidential files to third-party cloud servers, or place limits on file size. PDF Toolkit solves this by providing a completely free, offline-capable, privacy-focused local web application built entirely using standard Python libraries.

2. System Architecture & Modules

Module Underlying Library Description
PDF Metadata pypdf / PyMuPDF Reads document page count, size, author, and encryption state.
Merge & Split pypdf.PdfWriter Merges page streams, splits pages into ZIP archives.
Text Extraction pdfplumber / fitz Parses layout text streams, counts words and characters.
OCR Recognition pytesseract + Pillow Renders PDF pages to images and extracts text from scans.
Table Extraction pdfplumber + pandas Detects cell borders, formats HTML tables & exports to CSV/Excel.
PDF Compression PyMuPDF + pypdf Garbage cleans streams, downsamples image DPI, deflates content.
History DB SQLite3 Stores operation logs, status badges, timestamps locally.

4. Viva Questions & Model Answers

Flask is a lightweight WSGI web framework that gives complete control over routes and request processing without heavy boilerplate. Python has the richest ecosystem for PDF manipulation (pypdf, PyMuPDF, pdfplumber), making Flask the ideal backend connector.

Scanned PDFs do not contain embedded text streams; they contain page images. The application uses PyMuPDF (fitz) to render each PDF page into a high-resolution PIL Image in memory. It then passes the image to Tesseract OCR via `pytesseract` to extract recognized characters.

Files are sanitized using `secure_filename()` to prevent path traversal attacks (`../`). File extensions are strictly validated to `.pdf`. Maximum upload size is enforced to prevent Denial of Service (DoS) memory exhaustion. Output files are assigned unique timestamped names.

Compression works through stream deflation (removing redundant PDF object streams), garbage collection of unreferenced objects, deduplicating fonts, and downsampling embedded raster images (reducing DPI from 300 to 140/90 DPI with JPEG quality re-encoding).
